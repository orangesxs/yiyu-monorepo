# 一隅(yiyu-server)接口文档

> Base URL:开发 `http://localhost:3000/api`(前端经 vite proxy 同源访问);生产由前端 `VITE_API_BASE` 指向。
> 版本:2026-09-11(统一响应包装 + 语义化路径 + 分页/服务端聚合改造后)。

---

## 1. 总则

### 1.1 统一响应包装(envelope)

所有接口(成功与失败)统一返回:

```jsonc
{
  "success": true,           // 业务成功与否(2xx 恒 true;错误恒 false)
  "code": 0,                 // 成功恒 0;失败 = HTTP 状态码
  "message": "",             // 成功恒为空串;失败为中文提示(可直接 toast)
  "data": { },               // 业务数据;无返回体时为 null
  "timestamp": 1789107840000        // 毫秒时间戳
}
```

失败示例(403):

```json
{ "success": false, "code": 403, "message": "账号已停用,请联系管理员", "data": null, "timestamp": 1789107840000 }
```

### 1.2 鉴权

- 登录/注册返回 JWT(7 天有效),后续请求带请求头 `Authorization: Bearer <token>`。
- 除 `POST /auth/login`、`POST /auth/register`、`GET /health` 外全部接口需登录(401 `请先登录`)。
- `/admin/*` 另要求 `role=admin`(403 `需要管理员权限`)。
- **停用即时生效**:账号被停用后,已持有的 token 下一次请求即 401(服务端每请求查库)。

### 1.3 错误码一览

| HTTP / code | 场景 |
|---|---|
| 400 | 参数校验失败(多条错误以 `;` 拼接为一句)、业务规则拒绝(重名、超额度、区间非法等) |
| 401 | 未登录 / token 过期 / 账号被停用或删除 |
| 403 | 无权操作他人资源;非 admin 访问 admin 组;停用账号登录 |
| 404 | 资源不存在;**旧路径(/books、/invite-codes 等已废弃路径)** |
| 409 | 用户名已存在 |
| 429 | 限流(全局 60 次/分;登录/注册 5 次/分) |
| 500 | 服务器内部错误(`服务器开小差了`) |

### 1.4 数据约定

- 时间:`YYYY-MM-DD HH:mm`(Asia/Shanghai);日期:`YYYY-MM-DD`;月份键:`YYYY-MM`。
- 金额:number,单位元,最多 2 位小数,>0 且 ≤99,999,999。
- 分页统一结构:`{ total, page, pageSize, items }`;`page` 从 1 起,`pageSize` 1-100。

### 1.5 路径规范

资源按业务域分组(名词复数 + 层级前缀):`/auth/*`、`/profile/*`、`/profile/invite-codes`、`/ledger/*`、`/portal/*`、`/admin/*`。

## 2. 认证 auth

### 2.1 POST /auth/register — 注册(邀请码)

公开。请求体:

```json
{ "username": "zeo", "nickname": "小泽", "password": "yiyu123456", "inviteCode": "LLKK2345" }
```

| 字段 | 校验 |
|---|---|
| username | 2-20 位,仅 `字母/数字/下划线`,全站唯一(冲突 409 `用户名已存在`) |
| nickname | 1-20 字 |
| password | ≥6 位 |
| inviteCode | 8 位;须未使用(错误 400 `邀请码无效或已被使用`) |

成功 `data`:`{ token, user }`(注册即登录)。注册成功自动创建默认账本「日常账本 📘」并消耗该邀请码。

### 2.2 POST /auth/login — 登录

公开。`{ "username": "an", "password": "yiyu123456" }`

成功 `data`:`{ token, user }`。失败 401 `用户名或密码错误`;停用账号 403 `账号已停用,请联系管理员`。

### 2.3 POST /auth/logout — 登出

仅记审计日志(无状态 JWT,不做服务端注销)。`data`: `{ ok: true }`。

### 2.4 GET /auth/me — 当前用户

`data`:

```json
{ "id": "u1", "username": "an", "nickname": "安", "avatar": "🧑‍💻", "role": "admin" }
```

`role`(`admin | user`)是前端全站唯一的管理员判定依据。token 失效/停用/删除均 401。

## 3. 个人档案 profile

### 3.1 GET /profile — 我的档案

```json
{
  "id": "u1", "username": "an", "nickname": "安", "avatar": "🧑‍💻",
  "bio": "记一隅,见生活", "gender": "secret", "birthday": "1996-08-08",
  "region": "广东 · 深圳", "joinedAt": "2026-08-01", "updatedAt": "2026-09-10 18:00"
}
```

`gender`:`secret | male | female`;`birthday` 空串或 `YYYY-MM-DD`。

### 3.2 PUT /profile — 更新档案

请求体全部可选(nickname 1-20 / avatar emoji ≤8 / bio ≤60 / gender 三值 / birthday 日期或空 / region ≤30):

```json
{ "nickname": "安安", "avatar": "🌱", "bio": "", "gender": "secret", "birthday": "", "region": "" }
```

返回更新后的完整档案。

### 3.3 PUT /profile/password — 修改密码

`{ "oldPassword": "旧密码", "newPassword": "新密码至少6位" }`;旧密码错误 400 `当前密码不正确`。`data`: `{ ok: true }`。

## 4. 我的邀请码 /profile/invite-codes

### 4.1 GET /profile/invite-codes — 我的码列表

```json
[
  { "id": "i1", "code": "LLKK2345", "createdAt": "2026-09-01 10:00", "usedAt": null, "usedBy": null },
  { "id": "i2", "code": "MMNN6789", "createdAt": "2026-09-02 11:00", "usedAt": "2026-09-05 09:00",
    "usedBy": { "id": "u3", "nickname": "妈妈", "avatar": "👩" } }
]
```

新在前;状态由 `usedAt` 推导。

### 4.2 POST /profile/invite-codes — 生成邀请码

非 admin 未使用码达上限(默认 5,env `INVITE_MAX_UNUSED`)→ 400 `未使用邀请码已达上限`;admin 不限。返回新生成的 `InviteCodeVo`。

## 5. 记账本 ledger

通用对象:

```jsonc
// Book
{ "id": "b1", "name": "日常账本", "icon": "📘", "monthExpense": 4123.74, "isDefault": true }
// Category(根分类树;custom=true 为我的自定义)
{ "id": "c1", "name": "餐饮", "icon": "🍜", "custom": false, "children": [{ "id": "c11", "name": "早餐" }] }
// Transaction
{ "id": "t1", "type": "expense", "amount": 12.34, "categoryId": "c11", "categoryName": "早餐",
  "bookId": "b1", "date": "2026-09-10 08:30", "note": "豆浆油条" }
```

### 5.1 GET /ledger/books — 账本列表

`data`:Book 数组;默认账本在前,`monthExpense` 为当月支出实时聚合。

### 5.2 POST /ledger/books — 新建账本

`{ "name": "装修账本", "icon": "🏗️" }`(name 1-20 字,icon emoji)。返回新 Book(月支出 0,非默认)。

### 5.3 GET /ledger/categories?type= — 分类树

`type` 可选 `expense | income`(不传则返回全部)。预置分类在前、自定义在后。所有人共用预置分类;自定义分类仅属主可见可用。

### 5.4 POST /ledger/categories — 新增自定义分类

`{ "type": "expense", "name": "撸铁", "icon": "🏋️" }`(name 1-10 字)。同 type 重名(含与预置)→ 400 `该分类名已存在`。

### 5.5 DELETE /ledger/categories/:id — 删除自定义分类

仅可删自己的自定义分类(预置/他人的 403)。已有流水不受影响:`categoryId` 置空、展示靠冗余 `categoryName`。`data`: `{ ok: true }`。

### 5.6 GET /ledger/transactions — 流水列表(服务端分页)

Query 参数:

| 参数 | 必填 | 说明 |
|---|---|---|
| bookId | 是 | 他人账本 403 `无权访问该账本` |
| from | 否 | `YYYY-MM-DD`(含当日) |
| to | 否 | `YYYY-MM-DD`(含当日) |
| page | 否 | 默认 1 |
| pageSize | 否 | 默认 20,最大 100 |

`data`:

```json
{ "total": 561, "page": 1, "pageSize": 50, "items": [ /* Transaction,时间倒序 */ ] }
```

### 5.7 POST /ledger/transactions — 记一笔

```json
{ "type": "expense", "amount": 12.34, "categoryId": "c11", "date": "2026-09-10 08:30", "note": "豆浆油条", "bookId": "b1" }
```

| 字段 | 校验 |
|---|---|
| type | `expense | income` |
| amount | >0、≤2 位小数、≤99,999,999 |
| categoryId | 须存在且 type 匹配;他人自定义分类 403 |
| date | `YYYY-MM-DD HH:mm` |
| note | 可选,≤60 字 |
| bookId | 须为本人的账本 |

**`categoryName` 由服务端根据分类派生**(不信任客户端)。返回新 Transaction。

### 5.8 PATCH /ledger/transactions/:id — 修改流水

请求体全字段可选(同 5.7,改 type/categoryId 时服务端重新校验并派生 categoryName)。非本人 403。返回更新后 Transaction。

### 5.9 DELETE /ledger/transactions/:id — 删除流水

非本人 403。`data`: `{ ok: true }`。

### 5.10 GET /ledger/reports — 报表聚合(服务端计算)

Query:`bookId`、`from`、`to` 三者必填(`YYYY-MM-DD`)。校验:from>to 或区间>10 年 → 400;他人账本 403。

`data`:

```json
{
  "stats":     { "income": 13310.85, "expense": 4123.74, "balance": 9187.11, "count": 15 },
  "daily":     [ { "date": "2026-09-01", "income": 0, "expense": 3266.65 } ],
  "monthly":   [ { "month": "2026-01", "income": 51254.31, "expense": 17255.37 } ],
  "categories": {
    "expense": [ { "name": "居住", "value": 3432.10 } ],
    "income":  [ { "name": "工资", "value": 13310.85 } ]
  }
}
```

| 字段 | 说明 |
|---|---|
| stats | 区间收支总计与笔数 |
| daily | 按日聚合;**仅区间 ≤92 天时返回**(周/月报表用),否则为 `[]` |
| monthly | 按月聚合(年报表用) |
| categories.expense / income | 按根分类聚合(**子分类金额归并到根分类名**),金额倒序 |

金额用 Decimal 累加后序列化,无浮点误差。前端报表页(趋势/占比/排行/日历热力)全部消费此端点。

## 6. 广场门户 portal

### 6.1 GET /portal/summary — 应用卡摘要

登录落地页唯一接口(应用内数据进应用才加载)。

```json
{ "apps": { "ledger": { "bookName": "日常账本", "bookIcon": "📘", "monthExpense": 4123.74, "monthIncome": 13310.85, "monthBalance": 9187.11 } } }
```

口径 = **默认账本当月**收支;无账本时全 0。

## 7. 管理后台 admin(全部 requiresAdmin)

### 7.1 GET /admin/users?keyword&role&status — 用户列表

keyword 模糊匹配用户名/昵称(不分大小写);role/status 精确。

```json
[ { "id": "u1", "username": "an", "name": "安", "avatar": "🧑‍💻", "role": "admin",
    "status": "active", "registeredAt": "2026-08-01 10:00", "lastActiveAt": "2026-09-10 18:00" } ]
```

### 7.2 POST /admin/users — 直接建号

`{ "username": "newbie", "name": "新人", "avatar": "🙂", "role": "user", "password": "yiyu123456" }`

不消耗邀请码,记 security 日志。用户名冲突 409。

### 7.3 PATCH /admin/users/:id — 改角色/状态

`{ "role": "admin" }` 或 `{ "status": "disabled" }`(可同时)。**操作自己 400** `不能修改自己的角色或状态`。停用即时生效(对方 token 下次请求 401)。

### 7.4 GET /admin/logs — 操作日志(服务端分页)

Query:`page`(默认 1)、`pageSize`(默认 20,≤100)、`module`(`auth|ledger|profile|admin`)、`action`(`login|create|update|delete|security`)、`operatorId`。

```json
{ "total": 64, "page": 1, "pageSize": 20,
  "items": [ { "id": "l1", "time": "2026-09-10 18:24", "moduleId": "ledger", "action": "delete",
    "operatorId": "u1", "summary": "删除了流水「材料」",
    "operator": { "id": "u1", "nickname": "安", "avatar": "🧑‍💻" } } ] }
```

时间倒序;操作人信息由日志项自带,无需二次查询。

### 7.5 GET /admin/dashboard — 数据概览

```json
{
  "userCount": 7, "adminCount": 1, "activeCount": 6, "disabledCount": 1,
  "bookCount": 3, "logCount": 64, "logTodayCount": 5, "logSecurityCount": 3,
  "logCountByDay": [ { "date": "2026-09-05", "label": "9/5", "count": 6 } ],
  "latestLogs": [ /* AdminLog,最近 8 条 */ ]
}
```

**只统计系统资源,不含流水与金额**(2026-09-10 口径);`logCountByDay` 为近 7 日(含今日)。

### 7.6 GET /admin/invite-codes — 全部邀请码

含 creator/usedBy 双方信息,新在前。

### 7.7 POST /admin/invite-codes — 生成邀请码

admin 无额度限制。返回 `{ id, code, createdAt }`。

## 9. 审计日志埋点(admin_logs)

| module | action | 触发点 |
|---|---|---|
| auth | login | 登录成功/失败、注册、登出 |
| ledger | create/update/delete | 记一笔、改/删流水、建账本、增/删自定义分类 |
| profile | update | 更新档案、修改密码 |
| admin | security/update/create | 建号、改角色、停用/启用、生成邀请码 |

摘要中文 ≤40 字,只追加不修改。

## 10. 前端页面 ↔ 接口对应(按需加载)

| 页面 | 首次进入触发 |
|---|---|
| 广场 | `GET /portal/summary` |
| 流水明细 | `GET /ledger/books` + `GET /ledger/categories`(×2)+ 当月 `GET /ledger/transactions` + `GET /ledger/reports` |
| 报表统计 | 同上基础数据 + `GET /ledger/reports`(本期/上期/年度总计共 3 次) |
| 账本管理 | `GET /ledger/books`(+categories) |
| 个人中心 | `GET /profile` + `GET /profile/invite-codes` |
| 管理后台各页 | 各自的 users / logs / dashboard / invite-codes |

刷新任意页面仅多一次 `GET /auth/me`(恢复登录态)。
