# 数据库设计

> PostgreSQL 17 + Prisma ORM。schema 单一事实源:`prisma/schema.prisma`;本文档为人读版,字段以 schema 为准。
> 命名说明:Prisma 默认表名为 PascalCase 单数(`User`/`Book`/…),字段 camelCase;金额用 `Decimal(12,2)`,时间统一 `timestamptz`。

## 总览(6 张表)

```
users ──┬──< invite_codes(creatorId / usedById)
        ├──< books ──< transactions >── categories(categoryId 可空)
        ├──< categories(ownerId 可空:自定义分类)
        └──< admin_logs(operatorId)
categories ──< categories(parentId:子分类)
```

- **users 是唯一用户表**:归一前端 mock 阶段的 SystemUser(后台目录)与 Profile(个人档案)两份数据,`role`/`status` 与 `bio`/`gender`/`birthday`/`region` 同表共存。
- 所有业务表都带 userId 维度,跨用户数据物理隔离由 `where userId` 保证(服务层归属校验)。

## users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| username | String @unique | 登录名,2-20 位 `[a-zA-Z0-9_]` |
| passwordHash | String | bcrypt(10 轮) |
| nickname | String | 展示昵称(≤12) |
| avatar | String | 头像 emoji |
| role | Role | `admin` \| `user`,默认 `user` |
| status | UserStatus | `active` \| `disabled`,默认 `active`;停用即拒绝登录且现有 token 失效(strategy 每请求查库) |
| bio / gender / birthday / region | — | 档案扩展字段;gender `secret\|male\|female`,birthday `Date?` |
| registeredAt / lastActiveAt / updatedAt | DateTime | registeredAt 建号时间;lastActiveAt 每次登录刷新 |

索引:`@@index([role, status])`(后台筛选)。

## invite_codes

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| code | String @unique | 8 位大写无歧义字符(`ABCDEFGHJKMNPQRSTUVWXYZ23456789`,无 I/L/O/0/1) |
| creatorId | String | 生成人 → users |
| usedById | String? @unique | 使用人 → users;**可空且全表唯一 ⇒ 天然一次性**(一个用户只能用一个码) |
| createdAt / usedAt | DateTime? | 状态由 usedAt 推导,无独立状态列 |

约束:非 admin 每人**未使用**码上限 5(`INVITE_MAX_UNUSED` 环境变量可调);admin 不限。

## books

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | 属主 → users |
| name / icon | String | 名称(≤12)/ emoji 图标 |
| isDefault | Boolean | 注册时自动创建「日常账本 📘」并置 true;列表排序 default 在前 |
| createdAt | DateTime | |

注意:**monthExpense 不落库**,`GET /books` 时按当月支出实时聚合返回。

## categories

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| ownerId | String? | **null = 全局预置分类**;非空 = 该用户自定义(custom) |
| type | CategoryType | `expense` \| `income` |
| name / icon | String | 同 type 下预置+自定义根分类不许重名(服务层校验) |
| parentId | String? | 父分类 → categories;**仅两级**:根分类挂在账本类型下,子分类(如 早餐/午餐)挂根分类 |
| createdAt | DateTime | |

预置分类(ownerId null)由 seed 写入:支出 9 根 23 子 + 收入 5 根,与前端原 mock 一致。删除自定义分类时:其流水的 `categoryId` 置 null、靠 `categoryName` 冗余兜底展示;子分类一并删除。

## transactions

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | 记账人 → users |
| bookId | String | 账本 → books(须属本人) |
| type | TxType | `expense` \| `income` |
| amount | Decimal(12,2) | 金额(元);> 0,最多两位小数,≤ 99,999,999(API 层校验) |
| categoryId | String? | → categories;分类被删后置 null |
| categoryName | String | **服务端派生的冗余分类名**,列表展示兜底,不信任客户端 |
| date | DateTime | 记账时间;API 出入参 `YYYY-MM-DD HH:mm`(Asia/Shanghai)字符串 |
| note | String? | 备注(≤50) |

索引:`@@index([userId, bookId, date])`(列表查询主路径)。

## admin_logs

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| time | DateTime | 操作时间 |
| module | LogModule | `auth` \| `ledger` \| `profile` \| `admin` |
| action | LogAction | `login` \| `create` \| `update` \| `delete` \| `security` |
| operatorId | String | 操作人 → users |
| summary | String @db.VarChar(40) | 中文一句话摘要(≤40 字) |

只追加,不修改不删除。列表接口联 `operator` 出昵称/头像。**埋点由 AuditService 显式调用**(登录/注册/建号/改角色/停用/记账 CRUD/改档案/改密码/生成邀请码等),写入失败不阻断主流程。

## 环境与迁移

```bash
pnpm prisma migrate dev    # 开发:应用迁移 + 重新生成 client
pnpm prisma migrate reset  # 重置:drop + 迁移 + seed(测试/演示用)
pnpm prisma db seed        # 仅 seed
```

`.env` 关键项:`DATABASE_URL`(本地 `postgresql://postgres@localhost:5432/yiyu`)、`JWT_SECRET`、`JWT_EXPIRES=7d`、`INVITE_MAX_UNUSED=5`、`PORT=3000`、`CORS_ORIGINS`。
