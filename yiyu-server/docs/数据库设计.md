# 数据库设计

> PostgreSQL 17 + Prisma ORM。schema 单一事实源:`prisma/schema.prisma`;本文档为人读版,字段以 schema 为准。
> 命名说明:Prisma 默认表名为 PascalCase 单数(`User`/`Book`/…),字段 camelCase;金额用 `Decimal(12,2)`,时间统一 `timestamptz`。

## 总览(11 张表)

```
users ──┬──< invite_codes(creatorId / usedById)
        ├──< books ──< transactions >── categories(categoryId 可空)
        ├──< categories(ownerId 可空:自定义分类)
        ├──< admin_logs(operatorId)
        ├──< agent_conversations ──< agent_messages(级联删)
        └──< agent_usage_logs(conversationId 可空,SetNull)
categories ──< categories(parentId:子分类)
system_configs / agent_skill_configs(独立 KV,无外键)
```

- **users 是唯一用户表**:归一前端 mock 阶段的 SystemUser(后台目录)与 Profile(个人档案)两份数据,`role`/`status` 与 `bio`/`gender`/`birthday`/`region` 同表共存。
- 所有业务表都带 userId 维度,跨用户数据物理隔离由 `where userId` 保证(服务层归属校验)。

## users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| username | String @unique | 登录名,2-20 位 `[a-zA-Z0-9_]` |
| passwordHash | String | bcrypt(10 轮) |
| nickname | String | 展示昵称(≤12) |
| avatar | String | 头像 emoji |
| role | Role | `admin` \| `user`,默认 `user` |
| status | UserStatus | `active` \| `disabled`,默认 `active`;停用即拒绝登录且现有 token 失效(strategy 每请求查库) |
| bio / gender / birthday / region | — | 档案扩展字段;gender `secret\|male\|female`,birthday `Date?` |
| registeredAt / lastActiveAt / updatedAt | DateTime | registeredAt 建号时间;lastActiveAt 每次登录刷新 |

索引:`@@index([role, status])`(后台筛选)。

## invite_codes

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| code | String @unique | 8 位大写无歧义字符(`ABCDEFGHJKMNPQRSTUVWXYZ23456789`,无 I/L/O/0/1) |
| creatorId | String | 生成人 → users |
| usedById | String? @unique | 使用人 → users;**可空且全表唯一 ⇒ 天然一次性**(一个用户只能用一个码) |
| createdAt / usedAt | DateTime? | 状态由 usedAt 推导,无独立状态列 |

约束:非 admin 每人**未使用**码上限 5(`INVITE_MAX_UNUSED` 环境变量可调);admin 不限。

## books

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | 属主 → users |
| name / icon | String | 名称(≤12)/ emoji 图标 |
| isDefault | Boolean | 注册时自动创建「日常账本 📘」并置 true;列表排序 default 在前 |
| createdAt | DateTime | |

注意:**monthExpense 不落库**,`GET /books` 时按当月支出实时聚合返回。

## categories

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| ownerId | String? | **null = 全局预置分类**;非空 = 该用户自定义(custom) |
| type | CategoryType | `expense` \| `income` |
| name / icon | String | 同 type 下预置+自定义根分类不许重名(服务层校验) |
| parentId | String? | 父分类 → categories;**仅两级**:根分类挂在账本类型下,子分类(如 早餐/午餐)挂根分类 |
| createdAt | DateTime | |

预置分类(ownerId null)由 seed 写入:支出 9 根 23 子 + 收入 5 根,与前端原 mock 一致。删除自定义分类时:其流水的 `categoryId` 置 null、靠 `categoryName` 冗余兜底展示;子分类一并删除。

## transactions

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | 记账人 → users |
| bookId | String | 账本 → books(须属本人) |
| type | TxType | `expense` \| `income` |
| amount | Decimal(12,2) | 金额(元);> 0,最多两位小数,≤ 99,999,999(API 层校验) |
| categoryId | String? | → categories;分类被删后置 null |
| categoryName | String | **服务端派生的冗余分类名**,列表展示兜底,不信任客户端 |
| date | DateTime | 记账时间;API 出入参 `YYYY-MM-DD HH:mm`(Asia/Shanghai)字符串 |
| note | String? | 备注(≤50) |

索引:`@@index([userId, bookId, date])`(列表查询主路径)。

## admin_logs

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| time | DateTime | 操作时间 |
| module | LogModule | `auth` \| `ledger` \| `profile` \| `admin` \| `agent` |
| action | LogAction | `login` \| `create` \| `update` \| `delete` \| `security` |
| operatorId | String | 操作人 → users |
| summary | String @db.VarChar(40) | 中文一句话摘要(≤40 字) |

只追加,不修改不删除。列表接口联 `operator` 出昵称/头像。**埋点由 AuditService 显式调用**(登录/注册/建号/改角色/停用/记账 CRUD/改档案/改密码/生成邀请码等),写入失败不阻断主流程。

## system_configs(AI 运行时配置 KV)

| 字段 | 类型 | 说明 |
|---|---|---|
| key | String @id | `ai.llm` \| `ai.persona` \| `agent.settings` |
| value | Json | 结构由 AgentConfigService 的 TS 接口约束(LLM 连接/人设 prompt/行为参数) |
| updatedBy | String | 最后修改人 username(admin) |
| updatedAt | DateTime | @updatedAt |

首张运行时配置表(此前配置只有 .env):后台「AI 设置」页读写,内存缓存写失效 + 60s TTL。apiKey 只存此处,对外回显一律脱敏尾 4 位。

## agent_conversations(AI 会话)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | → users |
| title | String | 默认「新对话」,首条用户消息 slice(0,16) 自动命名 |
| summary | String? | 旧对话滚动摘要(结构化键值文本,窗口外消息 LLM 压缩) |
| summarizedSeq | Int | 已摘要到哪条 seq(判断是否需要压缩) |
| lastMessageAt | DateTime | 会话列表排序键,落消息时刷新 |

索引:`@@index([userId, lastMessageAt(sort: Desc)])`。删除级联清消息;用量行 SetNull 保留。

## agent_messages(AI 消息)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| conversationId | String | → agent_conversations(Cascade) |
| seq | Int | 会话内单调递增(1..n),排序与分页游标;`@@unique([conversationId, seq])` |
| role | String | `user` \| `assistant` \| `tool` |
| kind | String | `text` \| `tool_calls` \| `tool_result` \| `confirm_card` |
| content | Json | 形状按 kind 判别(见下);明文存储,后台 UI 不可见对话内容 |
| meta | Json? | user:页面上下文;assistant:模型/耗时/是否中断 |

content 形状(前后端共享契约):

- `user/text`:`{text}` · `assistant/text`:`{text}`
- `assistant/tool_calls`:`{calls:[{callId,name,args}]}`
- `tool/tool_result`:`{callId,name,ok,summary,llmData?,card?}`
- `assistant/confirm_card`:`{confirmId,skillId,toolName,label,risk, args,preview:{lines},warning?, status:'pending'|'confirmed'|'cancelled'|'expired'|'executed'|'failed',expiresAt,result?}`——确认卡是消息流一员,状态就地更新(pending→confirmed→executed/failed;取消/超时/被取代→cancelled/expired),过期惰性判定(读取时比对 expiresAt),10 分钟 TTL。

## agent_skill_configs(技能启停覆盖)

| 字段 | 类型 | 说明 |
|---|---|---|
| skillId | String @id | registry id,如 `ledger.create_transaction` |
| group | String | `ledger` \| `profile` \| `common`(冗余,便于排查) |
| enabled | Boolean | 默认 true;**无记录=默认启用** |
| updatedBy / updatedAt | — | admin 后台「技能管理」页写入 |

技能本体在代码注册(SkillRegistry,各业务模块 OnModuleInit 声明),本表只存覆盖值;代码删技能后残留行无害。读取缓存 30s。

## agent_usage_logs(LLM 用量)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String @id | cuid |
| userId | String | → users |
| conversationId | String? | → agent_conversations(SetNull;测试连通/摘要异常时无会话) |
| kind | String | `chat`(对话轮) \| `summarize`(滚动摘要) \| `test`(连通测试,统计视图默认排除) |
| model | String | 模型名 |
| promptTokens / completionTokens | Int | 精确值(stream_options.include_usage);网关不给时按字符估算 |
| estimated | Boolean | true=估算值(统计口径标注) |
| latencyMs / ok / errorCode | — | 调用延迟/成败/失败码 |

粒度:**每次 LLM HTTP 调用一行**(一轮对话多工具往返=多行)。fire-and-forget 落库,失败不阻断对话。索引:`createdAt` / `[userId, createdAt]` / `conversationId`。

## 环境与迁移

```bash
pnpm prisma migrate dev    # 开发:应用迁移 + 重新生成 client
pnpm prisma migrate reset  # 重置:drop + 迁移 + seed(测试/演示用)
pnpm prisma db seed        # 仅 seed
```

`.env` 关键项:`DATABASE_URL`(本地 `postgresql://postgres@localhost:5432/yiyu`)、`JWT_SECRET`、`JWT_EXPIRES=7d`、`INVITE_MAX_UNUSED=5`、`PORT=3000`、`CORS_ORIGINS`。
