# 记账本 · 需求设计

> 模块路径:`/ledger`,应用身份:💰「把每一笔都记得清楚」,身份色 `--app-ledger`
> 涉及代码:`src/modules/ledger/`(types.ts · mock/ledger.ts · stores/ledger.ts · routes.ts · views/Transactions、Reports、Books)
> 现状:**纯前端 mock 实现**,数据存内存,刷新重置。以下按"当前已实现"描述,标注了未实现项。

## 1. 产品定位

一个轻量的多账本记账工具:日常开销、装修、旅行基金等不同场景分开记账互不打扰,附基础报表分析。

## 2. 领域模型

### 2.1 账本(Book)

| 字段 | 说明 |
|---|---|
| `id` / `name` / `icon` | 标识与封面图标(📘🏗️✈️ 等 10 选 1) |
| `isDefault` | 默认账本标记 |
| `monthExpense` | 本月支出(卡片展示用) |

预置:日常账本、装修账、旅行基金。**协同成员概念已移除(2026-09-10)**:Book 无 `memberIds`,单人使用。

### 2.2 流水(Transaction)

| 字段 | 说明 |
|---|---|
| `type` | `expense` 支出 / `income` 收入 |
| `amount` | 金额,两位小数 |
| `categoryId` / `categoryName` | 分类 id 与冗余名称 |
| `bookId` | 归属账本 |
| `date` | `YYYY-MM-DD HH:mm`,列表按此倒序 |
| `note` | 备注,≤50 字 |

**成员维度已移除**:Transaction 无 `memberId`,流水只有 分类/账本 两个业务维度(账户维度此前已移除)。

### 2.3 分类(Category)

两级结构,根分类带 emoji 图标:

- **支出 9 类**:餐饮(早/午/晚餐、零食饮料)、交通(地铁公交/打车/加油)、购物(日用/服饰/数码)、居住(房租/水电物业)、娱乐(电影演出/游戏/视频会员)、医疗(药品/体检)、人情(礼物/请客)、教育(书籍/课程)、宠物(猫粮/医疗)
- **收入 5 类**(无子分类):工资、兼职、理财、红包、退款
- **自定义分类**:记一笔时可新增(`name ≤6 字` + 图标 9 选 1,同名去重),平铺显示、可删除;删除不影响已有流水。装修/旅行账的流水使用了 `custom-expense-decor`/`custom-expense-trip` 等未注册分类 id,统计时按 `categoryName` 兜底。

## 3. 页面设计

### 3.1 流水明细(`/ledger/transactions`,默认页)

布局:头部区固定,下方列表区独立滚动(`overscroll-behavior: contain`)。

**月度头**:左右箭头切月(范围硬编码 2025-10 ~ 2026-09)+ 当月支出/收入/结余小计。

**筛选**:类型单选(全部/支出/收入)+ 分类下拉 + 备注关键词,三者叠加过滤。

**列表**:按天分组,日期头吸顶(sticky + 毛玻璃),显示当日支/收小计;每行 = 分类 emoji + 分类名 + 备注 + 金额(+绿收/−红支),跨账本流水带账本徽标;行尾悬浮删除按钮(二次确认)。

**记一笔抽屉**(点击"记一笔"或点行编辑):
1. 支出/收入 Tab(支出红框、收入绿框的大额输入)
2. 归属账本下拉
3. 分类宫格(4 列,子分类平铺,继承根分类图标;可现场增删自定义分类)
4. 日期时间 + 备注
5. 校验:金额 > 0、必选分类

空态:🧾 + "这个月还没有记录" + 记第一笔按钮。

### 3.2 报表统计(`/ledger/reports`)

数据源:独立选择账本(默认当前账本),不随全局账本切换。

**四个联动控件**:维度(支出/收入/总计)、时间段(周/月/年,默认月)、区间偏移(本期/上期/更早,←→ 步进,本期时不可前进)。mock 基准日固定 2026-09-07。

**指标卡**:当前维度总额(总计=结余,紫/绿/红三色系)+ 环比上期百分比与差额 + 日均;账本累计总收支不随时间段变。

**四类图表**(ECharts 按需注册,全部随控件联动):
1. **趋势折线**:周/月按日、年按 12 月;本期视图叠加"上期"灰色虚线对照;总计模式为收支相抵单线
2. **分类占比环形图**:按根分类聚合;总计模式下收支并列、各自配色;下方图例含金额与占比
3. **分类排行横条**:支出/收入 Top 8;总计模式收/支各取 Top 6 混排
4. **收支日历**(自绘,非 ECharts):周=近 7 天条、月=整月日历(周日开头,未来日置灰)、年=12 月格;按支出分 4 档热力着色(e1~e4,纯收日绿色),悬停显示当日收支明细;底部摘要"最贵的一天/支出最高的月份"

### 3.3 账本管理(`/ledger/books`)

- **账本卡片栅格**:封面图标、名称、本月支出;当前账本带徽标,点击切换(store `switchBook`,影响流水明细默认展示);卡片底部左侧显示"默认账本"标记(非默认为空),右侧"切换 →"悬浮提示。
- **新建账本弹窗**:名称 ≤12 字 + 封面图标 10 选 1。

## 4. 交互与视觉规范

- 金额色彩:支出一律红(`--color-expense` 系)、收入一律绿(`--color-income` 系);数字用 `.num` 类(等宽风格)。
- 日历热力 4 档按当期最大支出归一化:>66% / >33% / >12% / 其余。
- 删除类操作一律 ElMessageBox 二次确认,成功 ElMessage 提示。
- 窄屏(<768px):隐藏月度收支小计,卡片栅格降列。

## 5. 数据生成(mock)

`modules/ledger/mock/ledger.ts` 用固定种子(`seed=42`)确定性生成近 12 个月约 2000+ 笔流水,锚定 2026-09-07:

- **日常账本**:工作日 1~3 笔(周末 ×1.6 加权),含真人感备注池("公司楼下 麻辣烫""加班打车回家");周期项——1 号房租 3200、5 号水电(夏季翻倍)、10 号工资 12800(1 月加年终奖 26000)、12 号视频会员、18 号猫粮、26 号理发、每周一理财收益;低频人情(3.5%)/医疗(1.2%)
- **装修账**:10 个月约 20 笔大额低频(材料/人工/家具/家电/软装/设计)
- **旅行基金**:每月 8 号定存 2000 + 4 笔成都行预支
